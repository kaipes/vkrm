##  Разработка модуля обнаружения аномалий в промышленных системах водоснабжения на основе вероятностной трансформерной модели

Данный репозиторий содержит программную реализацию выпускной квалификационной работы, посвящённой обнаружению аномалий в промышленных системах водоснабжения на основе анализа многомерных временных рядов.

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/kaipes/vkrm.git
cd vkrm

Создайте и активируйте виртуальное окружение:

conda create --name anomaly-detection python=3.9
conda activate anomaly-detection

Установите зависимости:

pip install -r requirements.txt

При использовании GPU рекомендуется установить PyTorch с поддержкой CUDA:

pip install torch==2.1.0+cu111 -f https://download.pytorch.org/whl/torch_stab
